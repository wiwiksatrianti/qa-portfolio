
# Test Plan – HRIS Employee Management

## 1. Project Overview
This project focuses on testing the Employee Management module of a Human Resource Information System (HRIS).

The purpose is to ensure that employee data can be managed accurately and all functionalities work as expected.

## 2. Testing Objectives
- Verify employee data creation.
- Verify employee data modification.
- Verify employee detail display.
- Verify employee data deletion.
- Validate mandatory fields and input formats.
- Identify and report software defects.

## 3. Scope of Testing

### In Scope
- Add Employee
- Edit Employee
- View Employee Details
- Delete Employee
- Input Field Validation

### Out of Scope
- Payroll Processing
- Attendance Management
- Leave Management

## 4. Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing
- Regression Testing

## 5. Test Environment
- Application: HRIS Web Application (Simulation)
- Browser: Google Chrome
- Testing Type: Manual Testing

## 6. Entry Criteria
- Requirements are available.
- Test environment is accessible.
- Test scenarios are prepared.

## 7. Exit Criteria
- All planned test cases have been executed.
- Critical defects have been reported.
- Test results have been documented.

## 8. Deliverables
- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
